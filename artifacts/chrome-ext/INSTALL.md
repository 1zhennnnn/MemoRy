# MemoRy Chrome Extension 安裝說明

MemoRy 是一個 AI 知識管理工具，能自動摘要、標籤、語意搜尋你儲存的網頁內容。

---

## 安裝步驟

### 第一步：下載擴充功能檔案

從安裝包取得 `dist` 資料夾（或解壓縮 `memory-ext.zip`），放到你電腦上任意位置。

> ⚠️ 安裝後請勿移動或刪除此資料夾，否則擴充功能會失效。

---

### 第二步：在 Chrome 載入

1. 開啟 Chrome 瀏覽器，網址列輸入：
   ```
   chrome://extensions/
   ```

2. 右上角開啟「**開發人員模式**」（Developer mode）

   ![開發人員模式](https://i.imgur.com/placeholder.png)

3. 點左上角「**載入未封裝項目**」（Load unpacked）

4. 選擇剛才的 `dist` 資料夾 → 確認

5. 看到 MemoRy 出現在清單中即安裝成功 ✓

---

### 第三步：登入

1. 點擊瀏覽器右上角的 MemoRy 圖示，開啟側欄
2. 使用 **Email / 密碼** 或 **Google 帳號** 登入
3. 登入後即可開始使用

---

## 使用方式

### 側欄
點擊瀏覽器右上角的 MemoRy 圖示開啟側欄：

| 按鈕 | 功能 |
|------|------|
| 📄 擷取整頁文字 | 儲存目前網頁的完整內容，AI 自動摘要 |
| ✦ AI 助手 | 開啟 Dashboard 的 AI 問答頁面 |
| ↻ | 重新整理筆記列表 |

### 右鍵選單
在任意網頁選取文字後按右鍵：
- **儲存選取文字至 MemoRy** — 儲存選取的段落

### 鍵盤快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Alt + Shift + S` | 儲存選取文字 |
| `Alt + Shift + A` | 擷取整頁文字 |

## Dashboard（網頁版）

所有筆記都可以在 Dashboard 查看、搜尋、管理：

🔗 **https://memo-ry-azure.vercel.app**

功能包含：
- 時間軸瀏覽
- 知識星座圖（筆記關聯視覺化）
- AI 語意搜尋
- 每日學習報告
- AI 助手問答
- 匯出成 JSON / Markdown

---

## 注意事項

- 需要 Chrome 瀏覽器（版本 114 以上）
- 每個人的帳號資料完全獨立，不會互相看到
- 如果側欄沒有出現，請去 `chrome://extensions/` 確認 MemoRy 已啟用
