# MemoRy — 前端設計書

## 1. 設計原則

| 原則 | 說明 |
|------|------|
| **低干擾** | Extension 不妨礙正常瀏覽；只在需要時出現 |
| **即時回饋** | AI 處理中顯示 pending 狀態，完成後自動更新 |
| **資訊密度適中** | 卡片式筆記，摘要優先；需要時再展開全文 |
| **暗色優先** | Dashboard 與 Extension popup 預設暗色模式，減少視覺疲勞 |
| **漸進式功能** | 核心擷取→摘要→搜尋→日報，功能逐步揭露 |

### 2.2 暗/亮模式系統

模式切換透過 `<html data-theme="dark|light">` 屬性實現，邏輯集中於 `src/shared/theme.ts`：

```typescript
// 初始化（main.tsx 呼叫）
initTheme()          // 讀 localStorage → 套用 data-theme
// 切換（TopBar 按鈕呼叫）
toggleTheme()        // 切換並儲存至 localStorage，回傳新 Theme
// 讀取
getTheme(): Theme    // 回傳 'dark' | 'light'
```

TopBar 右上角顯示 ☀️（暗色模式時）/ 🌙（亮色模式時）切換按鈕。

### 3.4 Content Script — 浮動工具列（CaptureBar）

使用者在網頁選取文字後，在選取區域旁出現：

```
選取的文字區域
    ↑
┌──────────────────────────────┐
│  🧠 儲存至 MemoRy  [✕]       │
│                              │
│  備注：________________      │
│                              │
│  [✓ 儲存]  [📋 加入標籤]    │
└──────────────────────────────┘
    ↑
  定位：Selection 下方 8px，viewport 內自動調整
  寬度：320px
  背景：Gray-900 / 90% opacity + blur(8px)
  動畫：fadeIn + slideUp 150ms
```

**狀態轉換**：

```
初始態 → [儲存] → 
  loading（spinner）→ 
  success（✓ 已儲存！aiStatus: pending）→ 
  自動收起（2s 後）

失敗 → 
  error（❌ 儲存失敗，請重試）→ 
  [重試] 按鈕
```

## 5. 互動設計規格

### 5.1 AI 狀態呈現

| 狀態 | 視覺 | 說明 |
|------|------|------|
| `pending` | 橘黃色 pulse dot + 文字「處理中...」 | Spinner 動畫，不阻塞閱讀 |
| `done` | 藍紫色 filled dot | 靜態，代表 AI 已完成 |
| `failed` | 紅色 dot + [重試] 連結 | 顯示失敗原因（hover tooltip） |

**Pending pulse 動畫**（CSS）：
```css
@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.4; }
}
.status-pending { animation: pulse 1.5s ease-in-out infinite; }
```

**polling 策略**（前端）：
```
筆記建立後 aiStatus=pending：
  每 3 秒 GET /api/notes/:id
  最多 60 秒（20 次）
  成功後更新 React Query cache，自動 re-render
  超時後顯示 "AI 處理超時，稍後請重試"
```

### 5.2 搜尋體驗

```
用戶輸入「...」
↓（debounce 300ms）
語意搜尋：顯示 loading skeleton
↓（API 回傳）
顯示 AI 回答 + 來源卡片（fadeIn 動畫）

切換「關鍵字搜尋」：
  立即呼叫 GET /search/keyword
  無 AI 回答區塊
  結果呈現同 NoteCard 列表
```

## 9. 資料流設計

### React Query 策略

```typescript
// 筆記列表：每 30 秒 refetch，分頁 cache
useQuery({
  queryKey: ["notes", { page, filters }],
  queryFn: () => getNotes(params),
  staleTime: 30_000,
})

// 單一筆記 + pending 輪詢
useQuery({
  queryKey: ["note", id],
  queryFn: () => getNote(id),
  refetchInterval: (data) =>
    data?.aiStatus === "pending" ? 3_000 : false,
})

// 搜尋：debounce 300ms 後觸發
useQuery({
  queryKey: ["search", query],
  queryFn: () => postSearch({ query }),
  enabled: query.length > 2,
  staleTime: 60_000,
})
```

## 10. 技術選型（前端）

| 項目 | 選擇 | 理由 |
|------|------|------|
| 框架 | React 18 | 生態成熟，Extension + Web 共用元件 |
| 建構 | Vite 6 | 快速 HMR，MV3 支援（vite-plugin-web-extension） |
| 樣式 | Tailwind CSS v4 | Utility-first，暗色模式簡單，無 CSS 衝突 |
| 狀態 | React Query v5 | Server state 管理，polling、cache、optimistic update |
| Auth | @supabase/auth-js | JWT 管理、token refresh |
| 路由 | React Router v7 | Dashboard SPA 路由 |
| 圖示 | Lucide React | MIT，tree-shakeable，一致性佳 |
| 日期 | date-fns | 輕量，比 dayjs 更 tree-shakeable |
| Markdown | react-markdown | 日報 crossDomain 欄位渲染 |
| 動畫 | Framer Motion | CaptureBar、sidebar 展開動畫 |
