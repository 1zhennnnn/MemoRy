## 1. Toast 通知文案

### 成功（3 秒後自動消失）

| 情境 | 文案 |
|------|------|
| 文字筆記儲存 | ✦ 筆記已儲存，AI 處理中... |
| 圖片截圖儲存 | ✦ 截圖已儲存，AI 分析中... |
| 筆記刪除 | 筆記已刪除 |
| 備注更新 | 備注已儲存 |
| 標籤更新 | 標籤已更新 |
| 日報生成完成 | ✦ 知識日報已生成 |
| 匯出完成 | ✦ 匯出完成，請查看下載 |
| 日記自動儲存 | ✓ 已自動儲存 |

### 警告（5 秒後自動消失）

| 情境 | 文案 |
|------|------|
| AI 摘要失敗 | ⚠ AI 處理失敗，原文已保存 |
| AI 處理逾時 | ⚠ AI 處理超時，可稍後重試 |
| 日報生成失敗 | ⚠ 日報生成失敗，請稍後再試 |
| Embedding 失敗 | ⚠ 語意索引失敗，搜尋可能受影響 |

### 錯誤（需手動關閉）

| 情境 | 文案 |
|------|------|
| 網路連線失敗 | ✕ 連線失敗，請確認網路狀態 |
| 登入過期 | ✕ 登入已過期，請重新登入 |
| 無權限 | ✕ 沒有存取此資源的權限 |
| 伺服器錯誤 | ✕ 伺服器發生錯誤，請稍後再試 |
| 截圖失敗 | ✕ 截圖失敗，請重新嘗試 |
| 檔案過大 | ✕ 圖片過大（超過 15MB），請縮小後再試 |

## 2. Empty State 文案

| 情境 | 主標題 | 說明 | 操作按鈕 |
|------|--------|------|---------|
| 無任何筆記 | 還沒有筆記 | 安裝 Extension，開始擷取你的知識碎片 | 安裝 Extension |
| 搜尋無結果（語意） | 找不到相關筆記 | 試試換個問法，或用關鍵字搜尋 | — |
| 搜尋無結果（關鍵字） | 找不到「{keyword}」 | 確認拼字或嘗試相關詞彙 | — |
| 日報尚未生成 | 今日日報尚未生成 | 需要至少 3 筆筆記才能生成日報 | 立即生成 |
| 日報無筆記（歷史） | 這天沒有筆記 | 這一天還沒有擷取任何內容 | — |
| 標籤無筆記 | 此標籤下沒有筆記 | 擷取筆記時 AI 會自動加上標籤 | — |
| 相關筆記無結果 | 還沒有相關筆記 | 多擷取一些筆記，知識連結會越來越豐富 | — |
| Extension Sidebar 空 | 找不到相關筆記 | 目前頁面與你的知識庫相關度較低 | — |

## 11. API 錯誤碼對應文案

| API 錯誤碼 | 使用者介面顯示 |
|-----------|-------------|
| `UNAUTHORIZED` | 登入已過期，請重新登入 |
| `FORBIDDEN` | 沒有存取此資源的權限 |
| `NOT_FOUND` | 找不到此筆記 |
| `MISSING_FIELD` | 請填寫必要欄位 |
| `INVALID_INPUT` | 輸入格式不正確 |
| `CONFLICT` | 此內容已存在 |
| `AI_ERROR` | AI 處理失敗，原文已保存 |
| `INTERNAL` | 伺服器錯誤，請稍後再試 |

## 12. 使用說明（Onboarding，未來）

```
第 1 步：安裝 Extension
  在任何網頁選取文字，右鍵選「儲存至 MemoRy」

第 2 步：AI 自動整理
  系統自動生成標題、摘要和標籤

第 3 步：搜尋你的知識
  用自然語言問問題，AI 從你的筆記中找答案

第 4 步：每日知識日報
  每天回顧今日學習，發現跨域連結
```
