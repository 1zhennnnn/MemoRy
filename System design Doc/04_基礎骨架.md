## 2. 已建立的核心檔案

### 2.1 `artifacts/api-server/src/app.ts`

```typescript
import express from "express";
import cors from "cors";
import { pinoHttp } from "pino-http";
import { logger } from "./lib/logger.js";
import { errorHandler } from "./lib/errors.js";
import router from "./routes/index.js";

const app = express();

app.use(pinoHttp({ logger }));
app.use(cors());
app.use(express.json({ limit: "15mb" }));

app.use("/api", router);
app.use(errorHandler);

export default app;
```

### 2.2 `artifacts/api-server/src/routes/index.ts`

路由掛載順序（重要）：

```typescript
import { Router } from "express";
import healthRouter   from "./health.js";
import notesRouter    from "./notes.js";
import searchRouter   from "./search.js";
import reportsRouter  from "./reports.js";
import tagsRouter     from "./tags.js";
import exportRouter   from "./export.js";

const router = Router();

router.use(healthRouter);    // GET /healthz
router.use(notesRouter);     // /notes, /notes/text, /notes/image, /notes/:id
router.use(searchRouter);    // /search, /search/keyword
router.use(reportsRouter);   // /reports, /reports/generate, /reports/:date
router.use(tagsRouter);      // /tags
router.use(exportRouter);    // /export

export default router;
```

> **注意**：`/notes/text` 和 `/notes/image` 必須在 `/notes/:id` 之前定義（靜態路徑優先）。  
> 同理，`/reports/generate` 在 `/reports/:date` 之前。

### 2.3 `artifacts/api-server/src/lib/errors.ts`

```typescript
export const ERROR_CODES = {
  UNAUTHORIZED: "UNAUTHORIZED",
  FORBIDDEN:    "FORBIDDEN",
  NOT_FOUND:    "NOT_FOUND",
  MISSING_FIELD: "MISSING_FIELD",
  INVALID_INPUT: "INVALID_INPUT",
  CONFLICT:     "CONFLICT",
  AI_ERROR:     "AI_ERROR",
  INTERNAL:     "INTERNAL",
} as const;

export type ErrorCode = keyof typeof ERROR_CODES;

export class AppError extends Error {
  constructor(
    public message: string,
    public code: ErrorCode | string,
    public status: number,
  ) {
    super(message);
  }
}

export function errorHandler(err, req, res, next) {
  if (err instanceof AppError) {
    return res.status(err.status).json({
      error: { code: err.code, message: err.message }
    });
  }
  req.log.error({ err }, "Unhandled error");
  res.status(500).json({
    error: { code: "INTERNAL", message: "Internal server error" }
  });
}
```

### 2.4 `artifacts/api-server/src/lib/ai.ts`

AI 模組提供以下函式（詳細實作見原始檔案）：

| 函式 | 說明 | 輸入 | 輸出 |
|------|------|------|------|
| `summarizeText(text)` | 生成摘要 + 標題 + 標籤 | string | `{ title, summary, tags }` |
| `ocrImage(base64)` | 圖片 OCR 提取文字 | base64 string | string |
| `embedText(text)` | 生成 768 維向量 | string | number[] |
| `ragAnswer(query, contexts)` | RAG 問答彙整 | query + 上下文陣列 | string |
| `generateDailyReport(notes)` | 生成每日知識日報 | 筆記陣列 | `{ keyLearnings, crossDomain, suggestions }` |

所有函式失敗時拋出 `AppError`，上層使用 `try/catch` 處理降級。

### 2.5 `artifacts/api-server/src/middlewares/auth.ts`

JWT 驗證流程：

```
請求進入
↓
讀取 Authorization: Bearer <token>
↓
若設有 SUPABASE_JWT_SECRET → jose.jwtVerify()（驗簽章）
否則 → parseJwtPayload()（僅解析，開發用）
↓
提取 payload.sub → req.user.id
提取 payload.email → req.user.email（選填）
↓
next() / next(AppError UNAUTHORIZED)
```

### 2.6 `lib/db/src/schema/notes.ts`（pgvector customType）

```typescript
import { customType } from "drizzle-orm/pg-core";

export const vectorColumn = customType<{
  data: number[];
  driverData: string;
  config: { dimensions: number };
}>({
  dataType(config) {
    return `vector(${config?.dimensions ?? 768})`;
  },
  toDriver(value) {
    return `[${value.join(",")}]`;
  },
  fromDriver(value) {
    return value
      .replace(/^\[|\]$/g, "")
      .split(",")
      .map(Number);
  },
});
```

## 3. 環境變數

## 4. 主要 npm Scripts

```bash

pnpm --filter @workspace/api-server run dev   # 啟動 API server (port 5000)

# 型別檢查
pnpm run typecheck                             # 全專案檢查
```
