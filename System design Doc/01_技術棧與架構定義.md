# MemoRy — 技術棧與架構定義

## 1. 系統概覽

MemoRy 是一套「AI 碎片化知識管理系統」，核心功能包含：

- **Chrome Extension（MV3）**：右鍵擷取文字或截圖，AI 自動摘要、標籤
- **Web Dashboard**：時間軸瀏覽、語意搜尋、日報回顧
- **語意搜尋（RAG）**：自然語言查詢 → 向量召回 → LLM 彙整
- **每日知識日報**：AI 自動生成學習要點 + 跨域聯想

## 3. 架構決策（ADR）

### ADR-001：Contract-First API

**決策**：OpenAPI spec（`lib/api-spec/openapi.yaml`）是唯一真相來源。

**理由**：
- 前後端型別自動同步，避免 drift
- codegen 生成 Zod 驗證 schema + React Query hooks，減少手寫量
- 任何端點異動必須先改 spec，再改實作

**約束**：
- 禁止先寫路由再補 spec
- codegen 後務必執行 `pnpm run typecheck`

---

### ADR-002：非同步 AI 處理

**決策**：筆記建立立即回傳 202，AI 摘要與 Embedding 在背景執行。

**理由**：
- Gemma API 呼叫延遲 1-5 秒，同步等待體驗差
- 使用者不需要等待即可繼續操作

**實作**：
```
POST /notes/text  →  立即建立 note（aiStatus="pending"）
                  →  void triggerEmbedding(...)  ← 背景執行
                  →  return 201 { noteId, aiStatus: "pending" }

前端輪詢 GET /notes/:id 直到 aiStatus="done" | "failed"
```

---

### ADR-003：AI 降級策略

**決策**：任何 AI 呼叫失敗不中斷主流程。

**行為**：
- `aiStatus = "failed"`
- 原始文字仍完整保存於 `sourceText` / `ocrText`
- 使用者可手動重試（未來功能）

---

### ADR-004：時間加權向量搜尋

**決策**：RAG 搜尋以 cosine distance × 時間衰減因子排序。

**公式**：
```sql
score = cosine_distance * (1 + 0.01 * days_since_created)
```
確保近期知識在同等相關性下優先顯示。

---

### ADR-005：JWT 自行驗證

**決策**：後端使用 `jose` 以 HS256 + `SUPABASE_JWT_SECRET` 驗證 token，不依賴 Supabase SDK。

**理由**：
- 減少外部依賴
- 邏輯透明可測試
- 若無設定 `SUPABASE_JWT_SECRET`，fallback 至 parse-only 模式（僅開發用）

## 4. Monorepo 結構

```
memory/
├── artifacts/
│   ├── api-server/          # Express 5 後端（主要後端）
│   └── mockup-sandbox/      # 元件預覽（Canvas 用）
│
├── lib/
│   ├── db/                  # Drizzle ORM schema + drizzle-kit config
│   ├── api-spec/            # OpenAPI YAML + Orval codegen
│   └── api-zod/             # codegen 產出（Zod schemas + hooks）
│
├── docs/                    # 本目錄：設計文件
├── replit.md                # 專案快速參考
└── pnpm-workspace.yaml      # workspace catalog 與依賴釘版
```
