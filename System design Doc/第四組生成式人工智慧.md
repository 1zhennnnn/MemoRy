**一、 專題主題與問題定義**  
**1.1 品牌定位與產品主張**

  MemoRy 名稱來自於 Memo \+ Memory \+ Diary，是一套以「零負擔知識採集」為核心理念的 AI 日常順手記錄工具(以電腦網頁版為主)，聚焦在文字擷取、AI 摘要與個人日記管理三個核心體驗。MemoRy 支援兩種日常記錄方式：①選取網頁文字右鍵儲存、②截圖貼入側欄讓 AI 辨識文字。兩者都在儲存當下即完成 AI 摘要與語意標籤，形成可被語意搜尋的個人知識日記，讓知識可被隨時查詢、回顧。

**1.2 應用情境**  
  MemoRy 設計主要聚焦在日常應用：

* 場景一：閱讀新聞/部落格  
  看到有趣報導，右鍵選取重點段落儲存至 MemoRy。AI 自動生成摘要與標籤，下次用自然語言查詢題目或主題標籤即可找回，不再靠記憶翻書籤。  
* 場景二：截圖讀字存成筆記（圖片 OCR）  
  課堂投影片、電子書無法選取文字、手機截圖——只要貼入側欄，AI 自動辨識圖中的所有文字，並整理成摘要與標籤，直接存成可搜尋的筆記。  
* 場景三：學習筆記補充  
  閱讀教學文章時，把難懂段落存入，AI 改寫成易懂摘要，個人心得手動補充在下方。形成「原文精華 \+ 自己的話」雙層筆記，編輯後自動重新向量化。  
* 場景四：語意搜尋找回舊筆記（RAG 查詢）  
  在儀表板輸入「有沒有關於機器學習的筆記？」，系統自動比對所有筆記的語意向量，召回相關的紀錄，並由 AI 彙整成一段自然語言回答。或者閱讀某一主題的筆記，推薦相關或相似主題的歷史紀錄文章。


**1.3 預計解決的問題**

* **資訊過載及碎片化**  
  解決「收藏但不閱讀」的困境，將大量未經整理的連結與文字內容，自動轉化為精簡且易於吸收的摘要。透過系統化處理，讓使用者不需重新閱讀冗長原文，即可快速掌握重點，降低資訊負擔並提升閱讀效率。  
* **分類成本過高**  
  傳統手動標籤在面對大量資訊時，往往需要使用者反覆思考分類方式與標籤內容，導致整理過程耗時且增加決策負擔；同時，隨著資料累積，既有分類也不易維持與調整，影響後續資訊的查找與利用效率。本系統透過 AI 進行語意分析與自動分類，協助使用者快速完成初步整理，降低時間成本與認知負擔，讓資訊管理更輕量且可持續。  
* **多模態整合困難**  
  現代資訊不僅限於文字，還包含圖片、截圖等形式，尤其圖片中的文字資訊難以有效整理與搜尋。本系統整合多模態處理能力，將圖片中的文字內容轉換為可分析與檢索的資料，讓不同形式的資訊得以統一管理。  
* **資訊孤島與斷層**  
  我們經常會從不同網站收集各類資訊，包含社群媒體（如網頁版 Facebook）、內容平台（如 Medium）以及其他可透過瀏覽器取得的網站內容。這些資訊雖然來源多元，卻彼此分散且缺乏連結，導致難以建立整體脈絡與關聯。本系統透過整合與關聯分析，將來自各網站的資訊串接起來，形成有脈絡的知識網絡，避免資訊片段化，也提升後續查找與理解的效率。  
* **脈絡遺失（Context Loss）**  
  傳統書籤僅保存內容本身，卻忽略了當下擷取資訊時的想法、目的與情境背景。本系統加入日記式記錄機制，保留使用者當時的思考與使用場景，讓未來回顧時能理解資訊背後的意義，而不只是單純的內容。  
* **缺乏回饋機制**  
  多數使用者習慣「先存再說」，但缺乏後續回顧與整理的動力，導致資訊長期閒置。本系統透過 AI 自動生成日報或摘要，建立被動式回饋機制，促使使用者定期接觸已收藏內容，提升知識吸收與內化的機會。

**1.4 選題動機與價值**  
  在資訊爆炸的時代，使用者雖然習慣先「收藏」內容，卻往往陷入「存而不讀、存而難找」的困境。隨著時間累積，大量未整理的連結、文字與圖片資訊逐漸變得零散且重複，不僅難以分類與管理，也無法有效轉化為可用的知識。

* 實務價值  
  將知識管理的操作成本降至最低；AI 每日/週或主題回顧信讓知識持續發酵，不再只是一次性閱讀。  
* 使用者價值  
  幫使用者完成，讓使用者只需「閱讀」與「思考」。將靜態收藏夾升級為動態智慧日記：主動理解（AI 摘要）→ 主動分類（語意標籤）→ 主動關聯（RAG 召回）→ 主動成長（知識可被找回並被使用）。每一個環節都由 AI 處理。

**三、 文獻回顧與現有產品分析**   
**3.1 相關學術研究**

* **數位囤積現象：書籤夾只存不看的 HCI 根源**

   **Vitale, Janzen & McGrenere — ACM CHI 2018 Best Paper**  
【研究背景與問題】隨著數位裝置普及，人們面臨的不再只是「找不到資訊」的問題，而是「累積了大量資訊卻不知如何整理與再利用」的困境。Vitale 等人以質性研究方法探討使用者在個人數位資料管理上的行為模式。  
【核心發現】研究描繪出一個從「極簡主義（Minimalism）」到「數位囤積（Digital Hoarding）」的行為光譜。有囤積傾向的參與者習慣「先存再說」，不加思索地保存大量資料（包含文件、圖片、書籤），但後續幾乎從不整理，最終導致資訊超載與焦慮感。研究同時發現，囤積行為具有情境依賴性（context-dependent）——同一個使用者可能在照片上極簡、在文章書籤上卻嚴重囤積。本論文獲 CHI 2018 最佳論文獎（Best Paper Award）。  
【與本系統的關聯】MemoRy 直接回應此論文所揭示的囤積循環：透過 AI 在使用者「存入當下」自動完成摘要、語意標籤與向量索引，即使使用者日後完全不整理，每筆記錄也已具備可讀性與可搜尋性。換言之，MemoRy 是讓數位囤積行為「有意義」的工具，而非強迫使用者改變行為習慣。

* **數位囤積影響認知失誤：以中國大學生為樣本的實證研究**  
   **Liu & Liu — Frontiers in Psychology, 2025**  
  【研究背景與問題】數位囤積（digital hoarding）被定義為「持續累積數位內容且不願刪除的行為」，在年輕族群中尤為普遍。然而先前研究多將數位囤積視為結果變項，對其「負面認知後果」的探討仍不充分。Liu & Liu 以中國大學生為對象，系統性考察數位囤積行為如何透過疲勞感的中介，最終導致認知失誤（cognitive failures），並檢驗正念（mindfulness）作為調節變項的緩解作用。  
  【研究設計與核心發現】研究招募 801 名參與者完成問卷調查，以 SPSS PROCESS 巨集進行有調節的中介模型（moderated mediation）分析。主要發現：①數位囤積正向預測認知失誤，囤積程度越高，日常注意力錯誤、記憶錯誤的頻率越高；②疲勞感在數位囤積與認知失誤之間扮演完全中介角色——大量累積的數位資訊帶來資訊管理壓力，轉化為心理疲勞，進而損害認知表現；③高正念特質能顯著緩和數位囤積對疲勞感的影響。研究援引 Sparrow et al.（2011）提出的「Google 效應」指出，數位囤積者傾向以數位裝置作為外部記憶體，導致個體記住的是「資訊存放的位置」而非「資訊本身的內容」，使面對實際認知任務時難以有效提取知識。  
  【與本系統的關聯】此論文為 MemoRy 的核心設計價值提供了直接的實證支撐：使用者大量收藏網頁、截圖與連結的行為，本質上正是數位囤積的典型表現，且根據此研究，這種行為實際上會損害其認知能力。MemoRy 透過 AI 自動摘要與 RAG 語意搜尋，將「知道資訊存在哪裡」轉化為「真正理解資訊的意義」——直接對應 Sparrow et al. 的「Google 效應」問題，幫助使用者從外部記憶體依賴者，轉型為主動理解資訊的知識建構者。  
* **書籤的建立與廢棄困境 — Bergman, Whittaker & Schooler, 2021**  
  【研究背景與問題】書籤是使用者管理網頁資訊最普遍的工具，然而先前研究持續觀察到書籤「鮮少被使用」的現象，卻缺乏系統性量化佐證。  
  【研究設計與核心發現】研究招募 50 位參與者，每人收到 21 個目標 URL 進行再取回任務，其中 5 個來自參與者自己的書籤，以隨機順序呈現以避免提示效應。結果顯示：儘管多數參與者都有建立書籤的習慣，他們在取回任務中卻幾乎不使用書籤；更關鍵的是，書籤頁面的再取回成功率並無優於未被標籤的頁面——「建立書籤」這個動作本身不能有效提升日後找回該資訊的機率。書籤只有在高度可見（如工具列固定顯示）時才會被使用，否則便處於「視而不見」的廢棄狀態。  
  【與本系統的關聯】此研究定義了 MemoRy 的核心設計假設：傳統書籤失敗的根源不在於使用者記憶力，而在於缺乏「脈絡（Context）」。MemoRy 在存入當下同步生成 AI 摘要與標籤，確保每筆記錄回頭看仍看得懂；RAG 語意搜尋則解決「找不到」的問題，讓使用者不需記得當初的存檔關鍵字。  
* **NoteIt：多模態影片轉互動式筆記 — Zhao et al., ACM UIST 2025**  
  【研究背景與問題】學生觀看教學影片時普遍面臨「需要暫停記錄，或事後難以找回特定段落」的困境。現有自動筆記工具無法完整保留影片的階層式資訊結構，也缺乏符合使用者需求的互動格式。  
  【系統設計與實驗結果】NoteIt 由香港大學、香港中文大學與 Google 研究團隊共同開發，以多模態 LLM 同時分析影片的視覺畫面、語音字幕與文字標註，自動提取章節層級（chapter-level）與步驟層級（step-level）的階層結構，生成使用者可自訂格式的互動式筆記。論文進行了技術評估與比較式使用者研究（N=36），客觀指標表現優越，使用者對系統可用性與筆記完整性給予正面回饋。  
  【與本系統的關聯】NoteIt 驗證了「多模態輸入 → 結構化筆記」在真實學習情境中的 AI 可行性與使用者接受度。MemoRy 將此概念擴展至更日常的瀏覽情境，以截圖貼入取代影片分析，用 Gemma 4 E4B 完成類似的「視覺內容 → 結構化摘要」轉化。

**3.3 與現有產品的差異與延伸方向**

* **系統定位：從「庫存管理」→「自動編輯部」**  
  MemoRy 不僅是「幫你整理」，而是持續改寫你的知識狀態，讓知識不只是被存放，而是持續被重組、更新與進化  
* **知識演化邏輯：時效性加權檢索**   
  MemoRy 引入「時間加權檢索」技術作為系統演化的核心。在 RAG（檢索增強生成）流程中，系統會針對語義相近的知識碎片進行時間戳（Timestamp）比對，自動賦予近期存入的資料更高權重，並將其作為 AI 生成摘要與回答的主要參考依據。此機制確保了使用者的知識庫能隨著資訊更新而「自動遞補」，在保留歷史脈絡的同時，優先呈現最符合現況的認知狀態，達成真正的知識動態演化。  
* **行為輸出：主動式日報**  
  MemoRy 不只是被動生成摘要，而是主動將不同時間點的內容串聯起來，輸出具備「變化感」的日報或週報，例如：今天的發現如何改寫昨天的問題，讓使用者看到自己認知的演化過程。  
* **低摩擦多入口輸入**  
  MemoRy 不再依賴單一操作方式，而是支援多種資訊輸入管道，包括右鍵儲存、截圖上傳、與網頁內容收集。所有輸入會自動進行摘要、分類、語義向量化與關聯建構，讓使用者專注於「收集」，而非「整理」。  
* **多維度回顧介面**  
  除了傳統的清單與時間線檢視，MemoRy 提供更具彈性的回顧方式。使用者可以依照自訂的分類方式整理與瀏覽內容，也可以由系統根據語義關聯，自動提供不同的分群與回顧視角。讓回顧不僅停留在逐筆紀錄的查看，而是能在連續的內容流動中觀察概念之間的連結、延伸與變化，逐步呈現整體認知結構的演進脈絡。

**四、 預期成果與執行挑戰**   
**4.1  預期成果形式**  
本專題預計以　Chromium　為核心的瀏覽器擴充功能實現，基於 Chrome Extension Manifest V3（MV3）規範開發，為系統的主要使用者介面與知識入口。使用者安裝後即可在任意網頁上反白選取文字、框選圖片區域或透過右鍵選單觸發擷取，無需切換工具或手動整理。常駐側欄在使用者瀏覽時持續運作，即時顯示 AI 偵測到的歷史關聯碎片，以及支援自然語言輸入的語義搜尋與 RAG 知識問答介面。所有 AI 處理均在背景非同步執行，不影響正常瀏覽體驗。

* MemoRy Chrome Extension：

提供反白選取、右鍵選單等觸發方式，支援文字、圖片與截圖擷取。擷取後系統立即自動抓取來源 URL、頁面標題與時間戳記；AI 即時生成重點摘要與語義標籤，也可對截圖執行 OCR 與語義理解，使圖片內容具備可搜尋性。

* 即時互動側欄：

定位為「高效輸入與即時對話」入口。採瀏覽器側邊欄形式，支援使用者在不中斷閱讀的情況下，進行文字擷取、圖片貼入、AI 快速摘要以及針對單筆知識的即時問答。側欄設計以輕量化、低干擾為核心，確保「零負擔」的採集體驗。

* 日報生成：系統每日定時匯報。日報內容包含「今日學習要點」、「跨域聯想分析」、「明日探索建議」，以及開放式日記供使用者補充當下思考與個人理解，形成兼具客觀整理與主觀脈絡的複合式紀錄。  
* 網頁儀表板：  
  「日記」以時間軸呈現 AI 每日生成內容，支援按標籤、來源網域與時間區間篩選回溯；「主題聚合」將相似主題資料自動歸類，允許使用者從主題而非時間維度回顧知識。
