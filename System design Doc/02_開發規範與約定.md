# MemoRy — 開發規範與約定

## 1. 核心原則

1. **Contract-First**：先改 OpenAPI spec，再改程式碼
2. **型別安全優先**：禁止 `any`；所有邊界用 Zod 驗證
3. **AI 不阻塞主流程**：所有 AI 呼叫必須可降級
4. **顯式錯誤**：不靠 silent fallback，失敗就拋出 `AppError`
5. **不用 `console.log`**：伺服器端一律用 `req.log` 或 `logger`

## 3. API 開發流程

```
1. 在 lib/api-spec/openapi.yaml 新增或修改端點
   ↓
2. pnpm --filter @workspace/api-spec run codegen
   ↓
3. 在 artifacts/api-server/src/routes/ 實作路由
   （使用 codegen 生成的 Zod schema 驗證 req.body）
   ↓
4. pnpm run typecheck  ← 確認無型別錯誤
   ↓
5. curl localhost:80/api/<endpoint> 手動驗證
```

## 4. 錯誤處理規範

### AppError 使用

```typescript
// ✅ 正確：明確的錯誤碼 + HTTP 狀態
throw new AppError("Note not found", ERROR_CODES.NOT_FOUND, 404);
throw new AppError("Missing field: text", ERROR_CODES.MISSING_FIELD, 400);
throw new AppError("Forbidden", ERROR_CODES.FORBIDDEN, 403);

// ❌ 錯誤：直接 throw 原生 Error 或 res.status(400) 不走 next
throw new Error("something wrong");
```

### 錯誤碼清單

| 碼 | 說明 | HTTP |
|----|------|------|
| `UNAUTHORIZED` | 未認證或 token 無效 | 401 |
| `FORBIDDEN` | 已認證但無權限 | 403 |
| `NOT_FOUND` | 資源不存在 | 404 |
| `MISSING_FIELD` | 必填欄位缺失 | 400 |
| `INVALID_INPUT` | 格式或值不符規範 | 400 |
| `CONFLICT` | 資源衝突（唯一約束違反） | 409 |
| `AI_ERROR` | AI 呼叫失敗（不阻塞主流程） | — |
| `INTERNAL` | 未預期錯誤 | 500 |

## 5. 資料庫操作規範

### Drizzle ORM 查詢

```typescript
// ✅ 使用 Drizzle 型別安全查詢
const [note] = await db
  .select()
  .from(notesTable)
  .where(and(eq(notesTable.id, id), eq(notesTable.userId, userId)));

// ✅ req.params 轉型（Express 5 params 型別為 string|string[]）
const id = String(req.params.id);

// ✅ req.query 轉型
const domain = String(req.query.domain);

// ❌ 直接用原始 req.params / req.query 傳入 eq()
eq(notesTable.id, req.params.id)  // 型別錯誤
```

## 6. AI 呼叫規範

```typescript
// ✅ 正確：背景執行，不等待，失敗更新 aiStatus
async function triggerEmbedding(noteId: string, text: string) {
  try {
    const vector = await embedText(text);
    await db.update(notesTable).set({ embedding: vector, aiStatus: "done" })
      .where(eq(notesTable.id, noteId));
  } catch {
    await db.update(notesTable).set({ aiStatus: "failed" })
      .where(eq(notesTable.id, noteId));
  }
}

// 呼叫方式：
void triggerEmbedding(noteId, text);  // void = 不等待，不丟失錯誤
```

## 10. 安全規範

- **永遠不在日誌中印出** JWT token、API key、密碼
- **使用者隔離**：所有 DB 查詢必須帶 `userId` 條件
- **body 上限**：`express.json({ limit: "15mb" })`（圖片 base64 安全餘量）
- **Secrets**：透過 Replit Secrets 管理，不寫入程式碼或 `.env` 檔
